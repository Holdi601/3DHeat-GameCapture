# Assetto Corsa, ACC, AC EVO και AC Rally {#assetto-corsa-acc-ac-evo-and-ac-rally}

```bash
python -m heat3d_capture telemetry --game ac      -o laps   # Assetto Corsa
python -m heat3d_capture telemetry --game acc     -o laps   # Assetto Corsa Competizione
python -m heat3d_capture telemetry --game acevo   -o laps   # Assetto Corsa EVO
python -m heat3d_capture telemetry --game acrally -o laps   # Assetto Corsa Rally
```

Κώδικας: [`telemetry/kunos.py`](https://github.com/Holdi601/3DHeat-GameCapture/blob/main/heat3d_capture/telemetry/kunos.py).
Δοκιμές: `tests/test_kunos.py` (συνθετικές σελίδες). Δεν έχει τρέξει ακόμη απέναντι στα ζωντανά παιχνίδια.

## Από πού προέρχονται τα δεδομένα {#where-the-data-comes-from}

Τα παιχνίδια της Kunos δημοσιεύουν τηλεμετρία για εφαρμογές ως **ονομασμένες σελίδες κοινής μνήμης των Windows**
που γράφει το παιχνίδι και μπορεί να διαβάσει οποιοσδήποτε. Ο καταγραφέας τις ανοίγει μόνο για ανάγνωση
(`mmap` με όνομα ετικέτας), οπότε πρέπει να τρέχει **στον υπολογιστή όπου τρέχει το παιχνίδι**, στα Windows· αλλού
τερματίζει με μήνυμα. Οι σελίδες ανοίγουν μία φορά, όταν ξεκινά ο καταγραφέας. Η ασφαλής σειρά είναι να ξεκινήσετε
πρώτα το παιχνίδι και να μπείτε στο αυτοκίνητο· το αν το αντίστροφο δουλεύει δεν έχει ελεγχθεί.

| `--game` | Σελίδα φυσικής | Σελίδα γραφικών (μετρητής γύρων) | Στατική σελίδα (ονόματα) |
|---|---|---|---|
| `ac` | `Local\acpmf_physics` | `Local\acpmf_graphics` | `Local\acpmf_static` |
| `acc` | `Local\acpmf_physics` | `Local\acpmf_graphics` | `Local\acpmf_static` |
| `acrally` | `Local\acpmf_physics` | δεν χρησιμοποιείται | `Local\acpmf_static` |
| `acevo` | `Local\acevo_pmf_physics` | δεν χρησιμοποιείται | `Local\acevo_pmf_static` |

Η σελίδα φυσικής διαβάζεται 200 φορές το δευτερόλεπτο (`hz=200`)· ένα νέο δείγμα λαμβάνεται μόνο όταν αλλάξει το
`packetId` της και δεν είναι μηδέν. Τα πρώτα 800 bytes της σελίδας φυσικής έχουν την ίδια διάταξη και στα τέσσερα
παιχνίδια· η σελίδα του πρώτου παιχνιδιού εγγυάται μόνο 580 bytes, οπότε αν δεν μπορεί να ανοιχτεί αντιστοίχιση
800 bytes ο καταγραφέας πέφτει σε 580 και τα πεδία πέρα από αυτά λείπουν.

## Θέση {#position}

Καμία από τις σελίδες δεν έχει θέση οχήματος ως τέτοια, αλλά η σελίδα φυσικής κρατά **το σημείο επαφής κάθε
ελαστικού στον κόσμο** (μετατόπιση 420, τέσσερις τριάδες XYZ). Η θέση του οχήματος είναι ο μέσος όρος των τεσσάρων.
Μια σελίδα όπου όλα τα σημεία επαφής είναι μηδέν (μενού, γκαράζ) δεν δίνει δείγμα.

## Κανάλια {#channels}

| Κανάλι | Από | Σημειώσεις |
|---|---|---|
| `time` | το δικό ρολόι του καταγραφέα | δευτερόλεπτα από την έναρξη της εγγραφής, μετατοπισμένα στο πρώτο δείγμα του γύρου |
| `x`, `y`, `z` | μέσο σημείο επαφής ελαστικού | μέτρα κόσμου |
| `speed` | `speedKmh` / 3,6 | m/s |
| `throttle`, `brake`, `clutch` | `gas`, `brake`, `clutch` | 0..1 |
| `steer` | `steerAngle` | οι μονάδες του παιχνιδιού, κλιμακωμένες ανά γύρο σε -1..1 με τη μεγαλύτερη απόλυτη τιμή που χρησιμοποίησε ο γύρος, **μόνο αν** η τιμή αυτή υπερβαίνει το 1,05 (μια είσοδος ήδη στο -1..1 μένει ως έχει) |
| `gear` | `gear - 1` | το παιχνίδι μετράει 0 όπισθεν, 1 νεκρή, 2 πρώτη· γράφεται ως -1, 0, 1 ... |
| `rpm` | `rpms` | |
| `latAcc`, `vertAcc`, `longAcc` | `accG` x, y, z, επί 9,80665 | m/s² |
| `yaw`, `pitch`, `roll` | `heading`, `pitch`, `roll` | rad |
| `yawRate` | `localAngularVel` y | rad/s |
| `latVel`, `vertVel`, `longVel` | τοπική ταχύτητα στη μετατόπιση 568 | σύστημα οχήματος· μόνο όταν είναι μη μηδενική. Προς ποια πλευρά δείχνει το x τεκμηριώνεται και προς τις δύο κατευθύνσεις, γι' αυτό διαβάστε το μέγεθος της γωνίας παρέκκλισης, όχι το πρόσημό της |
| `drs`, `pitLimiter`, `boost` | `drs`, `pitLimiterOn`, `turboBoost` | |
| `brakeBias` | μετατόπιση 564 | μόνο στη σελίδα 800 bytes |
| `tcActive`, `absActive` | ACC, AC EVO, AC Rally: μετατοπίσεις 204 και 252, γράφονται ως 1 όταν είναι πάνω από 0· AC: `tcInAction`/`absInAction` από τη σελίδα 800 bytes όταν υπάρχει | βοηθήματα σε λειτουργία |
| `tireTemp.*` | `tyreCoreTemperature` | °C |
| `tireTempInner/Middle/Outer.*` | `tyreTempI/M/O` | °C |
| `tirePressure.*` | `wheelsPressure` | psi |
| `wheelLoad.*` | `wheelLoad` | N |
| `wheelSpeed.*` | `wheelAngularSpeed` | rad/s |
| `camber.*` | `camberRAD` | rad |
| `suspensionM.*` | `suspensionTravel` | m |
| `suspension.*` | υπολογίζεται | 0..1 της διαδρομής που χρησιμοποίησε ο γύρος (ελάχιστο έως μέγιστο του `suspensionM`) |
| `brakeTemp.*` | `brakeTemp` | °C |
| `slipRatio.*`, `slipAngle.*` | μετατοπίσεις 640, 656 (σελίδα 800 bytes) | διαιρεμένα με έναν τυπικό συντελεστή - βλ. παρακάτω |

Το AC Rally στέλνει τις θερμοκρασίες ελαστικών και φρένων σε kelvin: για `--game acrally`, κάθε τέτοια τιμή πάνω από
200 έχει αφαιρεθεί 273,15.

Το `wheelSlip` (μετατόπιση 56) αποκωδικοποιείται αλλά δεν γράφεται.

## Κλιμάκωση ολίσθησης {#slip-scaling}

Η Forza στέλνει ολίσθηση κανονικοποιημένη ώστε το 1 να είναι το όριο της πρόσφυσης. Η Kunos στέλνει τον φυσικό λόγο
ολίσθησης και τη γωνία ολίσθησης. Γι' αυτό ο καταγραφέας τις διαιρεί με έναν τυπικό συντελεστή ασφάλτου - **0,12**
για τον λόγο ολίσθησης και **0,14 rad (περίπου 8 μοίρες)** για τη γωνία - ώστε η ανάγνωση "πάνω από 1 σημαίνει
γλίστρημα" του viewer να ισχύει προσεγγιστικά, κρατά τις ακατέργαστες τιμές δίπλα τους, και γράφει
`"meta": {"slip": "scaled"}`. Για το πού ακριβώς χάνεται η πρόσφυση, ο viewer μετρά ανά αυτοκίνητο από τους ίδιους
τους γύρους. Βλ. [Ολίσθηση, παρέκκλιση και παράγωγα κανάλια](slip-and-drift.md).

## Γύροι {#laps}

- **AC και ACC** μετρούν γύρους στη σελίδα γραφικών (`completedLaps` στη μετατόπιση 132, ο χρόνος του τελευταίου
  γύρου σε χιλιοστά του δευτερολέπτου στη 144). Το `CounterSplitter` κλείνει έναν γύρο όταν αλλάξει ο μετρητής· ο
  γύρος σημειώνεται ολοκληρωμένος, με τον χρόνο του παιχνιδιού, μόνο αν ο μετρητής αυξήθηκε κατά ακριβώς ένα.
- **AC EVO και AC Rally** δεν διαβάζονται για γύρους (η σελίδα γραφικών του EVO έχει διαφορετική, μεγαλύτερη διάταξη·
  το AC Rally οδηγεί στάδια). Το `LineSplitter` χρησιμοποιεί ως γραμμή το σημείο όπου άρχισε η εγγραφή: ένας γύρος
  κλείνει όταν το αυτοκίνητο περάσει ξανά πιο κοντά στη γραμμή με την ίδια κατεύθυνση, και ένα στάδιο ή οποιαδήποτε
  εκτέλεση κλείνει όταν το αυτοκίνητο μένει ακίνητο για 8 δευτερόλεπτα.

Λεπτομέρειες και όρια: [Πώς χωρίζονται οι γύροι και τα στάδια](lap-splitting.md).

## Ονόματα πίστας και οχήματος {#track-and-car-names}

Διαβάζονται μία φορά, από τη στατική σελίδα, όταν φτάνει το πρώτο δείγμα: για AC, ACC και AC Rally το όχημα (UTF-16,
μετατόπιση 68) και η πίστα (μετατόπιση 134)· για AC EVO η πίστα και η διαμόρφωσή της (κείμενο μίας byte στις
μετατοπίσεις 136 και 169, ενωμένα με κενό) και καθόλου όχημα. Μπαίνουν στο αρχείο ως `track` και
`car: {"name": ...}`.

## Το αρχείο γύρου {#the-lap-file}

Το `game` είναι `assetto-corsa`, `assetto-corsa-competizione`, `assetto-corsa-evo` ή `assetto-corsa-rally`· το `meta`
είναι `{"slip": "scaled", "discipline": "rally"}` για το AC Rally και `{"slip": "scaled", "discipline": "circuit"}`
για τα άλλα τρία. Δεν γράφεται `surface`.

## Πηγές {#sources}

Το AC1 SDK κοινής μνήμης· η τεκμηρίωση κοινής μνήμης του ACC (v1.8)· η διάταξη του AC EVO όπως μετρήθηκε στο
`albertowd/live-telemetry-evo`· η διάταξη του AC Rally όπως διαβάζεται από το
`LuizZak/AssettoCorsaRallyTelemetryReader`. Βλ. [Παιχνίδια](games.md).
