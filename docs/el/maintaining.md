# Συντήρηση αυτών των τεκμηρίωσεων {#maintaining-these-docs}

Η λίστα ελέγχου για κάθε έκδοση, ώστε ο κώδικας, οι αγγλικές σελίδες και οι μεταφράσεις τους να μένουν
συγχρονισμένα. Κάντε τα βήματα με τη σειρά.

1. **Ξαναδημιουργήστε τις παραγόμενες σελίδες.**
   - Το `python tools/gen_docs_reference.py` ξαναγράφει τη [Σελίδα εντολών](../cli-reference.md) από το
     `--help` και τις λίστες στηλών του κώδικα. Το `--check` τερματίζει με 1 όταν η σελίδα είναι παλιά:
     τρέξτε το πριν από κάθε έκδοση.
   - Το `python tools/docs_diagrams.py` ξαναζωγραφίζει τα διαγράμματα στο `docs/assets/img/`· το
     `--strings` ανανεώνει επίσης το `docs/assets/i18n/en.json`, τις ετικέτες που πρέπει να μεταφραστούν.
   - Το `python tools/sync_wiki.py` ξαναδημιουργεί το αντίγραφο του wiki του GitHub στο `docs/wiki/`.
2. **Καταγράψτε τι άλλαξε από την τελευταία έκδοση.** `git log --oneline v$(cat VERSION)..` (η
   τελευταία ετικέτα είναι το `v` και η έκδοση στο `VERSION`). Για κάθε νέα ή αλλαγμένη εντολή, επιλογή,
   στήλη εξόδου ή συμπεριφορά: ενημερώστε τη σελίδα της και προσθέστε μια γραμμή στον πίνακα *Docs* του
   `CHANGELOG.md`.
3. **Ανεξάρτητη αναθεώρηση.** Κάποιος που δεν έγραψε την αλλαγή διαβάζει τις αλλαγμένες σελίδες και τα
   διαγράμματα με τρεις αναγνώστες: έναν **αρχάριο** (δεν έχει ποτέ χρησιμοποιήσει γραμμή εντολών: μπορεί
   να την εγκαταστήσει και να την τρέξει;), ένα **παιδί 8 ετών** (η σελίδα λέει με απλά λόγια τι είναι
   και γιατί;), και έναν **επαγγελματία** (οι επιλογές, οι προεπιλογές και οι στήλες ταιριάζουν με τον
   κώδικα;). Ελέγξτε ότι καμία σελίδα δεν αναφέρει πραγματικά επίπεδα, χάρτες, παίκτες ή καταγραφές:
   τα παραδείγματα είναι συνθετικά, και οι ισχυρισμοί επαλήθευσης δίνουν μόνο τη μέθοδο και την ανοχή.
4. **Διορθώστε τα ευρήματα.**
5. **Μεταφράστε.** Κάθε μεταφρασμένη σελίδα καταγράφει το hash της αγγλικής σελίδας από την οποία
   έγινε. Ξαναμεταφράστε τις σελίδες όπου άλλαξε το hash της αγγλικής πηγής, και τις ετικέτες των
   διαγραμμάτων που άλλαξαν· έπειτα ελέγξτε κάθε γλώσσα: καθαρή για τους τρεις αναγνώστες, σωστές
   ετικέτες στα διαγράμματα, λέξεις που ταιριάζουν με τη μεταφρασμένη διεπαφή του προβολέα.
6. **Ανεβάστε μόνο μετά την έγκριση του κατόχου.** Μετά, βάλτε στην έκδοση ετικέτα `v<VERSION>`.

Νέοι στην εκτέλεση αυτών των εντολών; Το [Πριν ξεκινήσετε](before-you-start.md) καλύπτει την Python και
το τερματικό.

## Μεταφράσεις: οι εντολές {#translations-the-commands}

Η τοποθεσία μεταφράζεται στις 40 γλώσσες του προβολέα 3DHeat: τα αγγλικά βρίσκονται στο `docs/`, κάθε
άλλη γλώσσα στο `docs/<lang>/` με τα ίδια ονόματα αρχείων. Το `tools/docs_i18n.py` κάνει τη λογιστική:

```bash
python tools/docs_i18n.py hashes             # μετά από κάθε αλλαγή στα αγγλικά: καταγράφει το hash κάθε σελίδας
python tools/docs_i18n.py svg-strings        # μετά από κάθε αλλαγή εικόνας: οι ετικέτες που πρέπει να μεταφραστούν
python tools/docs_i18n.py status             # ανά γλώσσα: τρέχουσες, παλιές, λείπουσες σελίδες
python tools/docs_i18n.py todo --lang de     # οι γερμανικές σελίδες που πρέπει να (ξαν)μεταφραστούν
python tools/docs_i18n.py svg-build --lang de    # γερμανικές εικόνες από το docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # σφραγίζει τις γερμανικές σελίδες με το hash των αγγλικών
python tools/docs_i18n.py check              # τερματίζει με 1 όταν τα hash ή οι ετικέτες είναι παλιά
```

Μεταφράζετε μόνο όσα δείχνει το `todo`: κρατήστε το Markdown, τους συνδέσμους, τον κώδικα και τα ονόματα
αρχείων και στηλών ως έχουν, μεταφράστε τους τίτλους και τις περιγραφές εικόνων, και χρησιμοποιήστε τις
δικές της λέξεις του προβολέα 3DHeat για τα κουμπιά και τα πλαίσιά του (τα `src/i18n/locales/<lang>/`
του). Οι παραγόμενες σελίδες αναφοράς και οι εικόνες του τερματικού μένουν αγγλικές. Στον ιστότοπο, μια
παλιά μετάφραση το λέει και συνδέει με την αγγλική σελίδα· μια λείπουσα πέφτει στα αγγλικά. Το μενού
γλωσσών της κεφαλίδας και η αυτόματη ανακατεύθυνση της αρχικής σελίδας με βάση τη γλώσσα του
προγράμματος περιήγησης προέρχονται από το `docs/_includes/`.
