# iRacing {#iracing}

iRacing **не бара снимач**. Симулаторот сам запишува свои датотеки со телеметрија, `.ibt`, кога
е вклучено снимањето на телеметрија (Alt+L во автомобилот): целата сесија на 60 Hz, секој
канал што го изложува симулаторот, со YAML-описот на сесијата до него. Спуштете ја датотеката
`.ibt` врз табот Анализа на трка на прегледувачот.

Читачот живее во прегледувачот, а не во ова складиште (`src/race/ibt.ts` во прегледувачот
3DHeat). Тестиран е на синтетичка датотека; документиран е овде затоа што е делот за iRacing од
истата приказна за снимање кругови.

## Што содржи датотеката и како се чита {#what-the-file-holds-and-how-it-is-read}

Датотеката е документираниот распоред на меморијата на симулаторот, запишан на диск:

| Дел | Големина | Содржи |
|---|---|---|
| Заглавје | 112 бајти | верзија, стапка на отчитување, каде се YAML и табелата на променливи, должина на еден ред со отчитување, каде почнуваат редовите |
| Под-заглавје на диск | 32 бајти | датум и време на почеток, број на кругови, број на редови |
| Табела на променливи | 144 бајти по канал | тип, поместување во редот, број, име, опис, единица |
| YAML | | `WeekendInfo`, `DriverInfo`, ... |
| Редови | еден по отчукување | |

Датотеката се одбива кога е пократка од 144 бајти, кога заглавјето не е разумно (нема
променливи, табела на променливи надвор од датотеката, нулта должина на ред), кога ѝ недостига
некое од `SessionTime`, `Lap`, `Lat`, `Lon`, или кога ниедно отчитување нема фиксирана позиција.

## Позиција {#position}

iRacing пријавува географска ширина, должина и надморска висина, а не позиција во сопствената
рамка на патеката. Позициите се распоредуваат во метри на рамнина тангента на првото отчитување
со фиксирана позиција (радиус на Земјата 6.371.008,8 m): `x` исток, `z` југ, `y` надморската
висина - така што одозгора, со основната насока на камерата на прегледувачот, северот е нагоре
на екранот.

## Кругови {#laps}

Сесијата се дели според бројачот `Lap` на симулаторот. Кругот се задржува само ако има повеќе
од 60 отчитувања, почнува под 5% од растојанието на кругот (`LapDistPct`) и завршува над 95% -
односно кругови возени од линија до линија. Ако ниеден круг не исполнува, датотеката се одбива
со порака што ја именува должината на патеката од YAML. `distance` е `LapDist` сведено на
почетокот на кругот, или возеното растојание од позициите кога `LapDist` недостига; `time` е
`SessionTime` од почетокот на кругот.

## Канали {#channels}

| iRacing | Канал | Претворање |
|---|---|---|
| `Speed`, `Throttle`, `Brake`, `Gear`, `RPM` | `speed`, `throttle`, `brake`, `gear`, `rpm` | нема |
| `Clutch` | `clutch` | `1 - value` (iRacing го брои спојката како вклучена; каналот е педалот) |
| `SteeringWheelAngle` | `steer` | `-angle / SteeringWheelAngleMax` (радијани, спротивно од стрелките на часовникот позитивно, во -1..1 десно позитивно; pi кога максимумот недостига) |
| `LatAccel`, `LongAccel`, `VertAccel` | `latAcc`, `longAcc`, `vertAcc` | нема |
| `Yaw`, `Pitch`, `Roll`, `YawRate` | `yaw`, `pitch`, `roll`, `yawRate` | нема |
| `BrakeABSactive` | `absActive` | |
| `dcABS`, `dcTractionControl` | `absLevel`, `tcLevel` | поставки на помагала |
| `dcBrakeBias` | `brakeBias` | поделено со 100 кога е над 1,5 (процент кај некои автомобили) |
| `dcPitSpeedLimiterToggle` | `pitLimiter` | |
| `FuelLevel`, `WaterTemp`, `OilTemp` | `fuel`, `waterTemp`, `oilTemp` | |
| `LFtempCM` ... `RRtempCM` | `tireTemp.FL` ... `.RR` | температура на карказата по средина |
| `..shockDefl` | `suspensionM.*` | |
| `..pressure` | `tirePressure.*` | kPa помножено со 0,145038, во psi |
| `..wearM` | `tireWear.*` | `1 - value` |

Секој друг канал со една вредност по отчитување (и не еден бајт) се пренесува под своето име,
при што префиксот на тркалото (`LF`, `RF`, `LR`, `RR`) се претвора во наставка (`.FL`, `.FR`,
`.RL`, `.RR`), па графиконите на прегледувачот го нудат без никој да го опишува.

Автомобилот доаѓа од `DriverInfo`: записот чиј `CarIdx` се совпаѓа со `DriverCarIdx` ги дава
`CarScreenName`, `CarID` и `CarClassShortName`. Патеката е `TrackDisplayName` (или `TrackName`).

## Што iRacing не дава {#what-iracing-does-not-give}

Не се запишува лизгање на гумите, па нема канали за лизгање. Аголот на дрифт се добива од
брзината на вртење околу вертикалата наспроти патеката (видете
[Лизгање, дрифт и изведени канали](slip-and-drift.md)). Моделите на патеките се испорачуваат во
заштитен формат и не се цел за вадење датотеки (видете [Игри](games.md)).
