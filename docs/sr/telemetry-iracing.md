# iRacing {#iracing}

iRacing-у није потребан **снимач**. Симулатор сам записује своје фајлове телеметрије, `.ibt`, кад је евиденција телеметрије укључена (Alt+L у аутомобилу): цела сесија на 60 Hz, сваки канал који симулатор излаже, с YAML описом сесије уз њих. Превуците `.ibt` фајл на картицу „Анализа трке" у прегледачу.

Читач је у прегледачу, а не у овом репозиторијуму (`src/race/ibt.ts` у 3DHeat прегледачу). Тестиран је на синтетичком фајлу; овде је документован јер је то iRacing део исте приче о снимању кругова.

## Шта фајл садржи и како се чита {#what-the-file-holds-and-how-it-is-read}

Фајл је документован распоред меморије симулатора записан на диск:

| Део | Величина | Садржи |
|---|---|---|
| Заглавље | 112 бајтова | верзија, брзина откуцаја, где су YAML и табела променљивих, дужина једног реда узорка, где редови почињу |
| Под-заглавље диска | 32 бајта | датум и време почетка, број кругова, број редова |
| Табела променљивих | 144 бајта по каналу | тип, помак у реду, број, назив, опис, јединица |
| YAML | | `WeekendInfo`, `DriverInfo`, ... |
| Редови | по један по откуцају | |

Фајл се одбија кад је краћи од 144 бајта, кад заглавље није исправно (нема променљивих, табела променљивих је ван фајла, дужина реда је нула), кад недостаје неки од `SessionTime`, `Lap`, `Lat`, `Lon`, или кад ниједан узорак нема фиксирану позицију.

## Положај {#position}

iRacing даје географску ширину, дужину и висину, а не положај у оквиру саме стазе. Положаји се постављају у метрима на равни која додирује први узорак са фиксом (полупречник Земље 6,371,008.8 m): `x` исток, `z` југ, `y` висина - тако да одозго, с подразумеваним правцем камере прегледача, север иде нагоре на екрану.

## Кругови {#laps}

Сесија се дели по бројачу `Lap` симулатора. Круг се задржава само ако има више од 60 узорака, почиње испод 5% дужине круга (`LapDistPct`) и завршава се изнад 95% - то јест кругови вожени од линије до линије. Ако ниједан круг не испуњава услов, фајл се одбија поруком која именује дужину стазе из YAML-а. `distance` је `LapDist` подешен на почетак круга, или пређена даљина из положаја кад `LapDist` недостаје; `time` је `SessionTime` од почетка круга.

## Канали {#channels}

| iRacing | Канал | Конверзија |
|---|---|---|
| `Speed`, `Throttle`, `Brake`, `Gear`, `RPM` | `speed`, `throttle`, `brake`, `gear`, `rpm` | нема |
| `Clutch` | `clutch` | `1 - value` (iRacing рачуна квачило као укључено; канал је педала) |
| `SteeringWheelAngle` | `steer` | `-angle / SteeringWheelAngleMax` (радијани, позитивно у смеру супротном од казаљке, на -1..1 десно позитивно; pi кад максимум недостаје) |
| `LatAccel`, `LongAccel`, `VertAccel` | `latAcc`, `longAcc`, `vertAcc` | нема |
| `Yaw`, `Pitch`, `Roll`, `YawRate` | `yaw`, `pitch`, `roll`, `yawRate` | нема |
| `BrakeABSactive` | `absActive` | |
| `dcABS`, `dcTractionControl` | `absLevel`, `tcLevel` | подешавања помоћи |
| `dcBrakeBias` | `brakeBias` | дели се са 100 кад је изнад 1.5 (проценат на неким аутомобилима) |
| `dcPitSpeedLimiterToggle` | `pitLimiter` | |
| `FuelLevel`, `WaterTemp`, `OilTemp` | `fuel`, `waterTemp`, `oilTemp` | |
| `LFtempCM` ... `RRtempCM` | `tireTemp.FL` ... `.RR` | температура карказе по средини |
| `..shockDefl` | `suspensionM.*` | |
| `..pressure` | `tirePressure.*` | kPa помножен са 0.145038, у psi |
| `..wearM` | `tireWear.*` | `1 - value` |

Сваки други канал с једном вредношћу по узорку (и не појединачним бајтом) пролази под својим именом, а префикс точка (`LF`, `RF`, `LR`, `RR`) претвара се у суфикс (`.FL`, `.FR`, `.RL`, `.RR`), па га графици прегледача нуде без описа било кога.

Аутомобил долази из `DriverInfo`: унос чији се `CarIdx` поклапа с `DriverCarIdx` даје `CarScreenName`, `CarID` и `CarClassShortName`. Стаза је `TrackDisplayName` (или `TrackName`).

## Шта iRacing не даје {#what-iracing-does-not-give}

Клизање гума се не бележи, па нема канала клизања. Угао дрифта изводи се из брзине скретања у односу на путању (погледајте [Клизање, дриф и изведени канали](slip-and-drift.md)). Модели стаза долазе у заштићеном формату и нису мета извлачења фајлова (погледајте [Игре](games.md)).
