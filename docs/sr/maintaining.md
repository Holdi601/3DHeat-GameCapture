# Одржавање ових докумената {#maintaining-these-docs}

Списак за свако издање, да код, енглеске странице и њихови преводи остану усклађени. Кораке радите редом.

1. **Поново направите генерисане странице.**
   - `python tools/gen_docs_reference.py` поново пише [Референца команди](../cli-reference.md) из `--help` и спискова колона у коду. `--check` излази са 1 кад је страница застарела: покрените га пре сваког издања.
   - `python tools/docs_diagrams.py` поново црта дијаграме у `docs/assets/img/`; `--strings` такође освежава `docs/assets/i18n/en.json`, ознаке за превод.
   - `python tools/sync_wiki.py` поново прави копију GitHub викија у `docs/wiki/`.
2. **Наведите шта се променило од последњег издања.** `git log --oneline v$(cat VERSION)..` (последња ознака је `v` + верзија у `VERSION`). За сваку нову или измењену команду, опцију, колону излаза или понашање: ажурирајте њену страницу и додајте ред у табелу *Docs* у `CHANGELOG.md`.
3. **Независан преглед.** Неко ко није написао промену чита измењене странице и дијаграме као три читаоца: **почетник** (никад није користио командну линију: може ли да инсталира и покрене?), **осмогодишњак** (да ли страница јасно речима каже шта је то и зашто?) и **стручњак** (да ли се опције, подразумеване вредности и колоне поклапају с кодом?). Проверите да ниједна страница не именује стварне нивое, мапе, играче или снимке: примери су синтетички, а тврдње о проверама дају само метод и толеранцију.
4. **Исправите налазе.**
5. **Превод.** Сваки превод бележи хеш енглеске странице из које је настала. Поново преведите странице чији се хеш изворника променио, и ознаке дијаграма које су се промениле; затим прегледајте сваки језик: јасно за три читаоца, исправне ознаке дијаграма, речи које се поклапају с локализованим интерфејсом прегледача.
6. **Објављујте тек уз дозволу власника.** Онда означите издање `v<VERSION>`.

Нови сте у покретању ових команди? [Пре почетка](before-you-start.md) објашњава Python и терминал.

## Преводи: команде {#translations-the-commands}

Сајт је преведен на 40 језика 3DHeat прегледача: енглески је у `docs/`, сваки други језик у `docs/<lang>/` с истим именима фајлова. `tools/docs_i18n.py` води евиденцију:

```bash
python tools/docs_i18n.py hashes             # after any English change: record each page's hash
python tools/docs_i18n.py svg-strings        # after any picture change: the labels to translate
python tools/docs_i18n.py status             # per language: current, outdated, missing pages
python tools/docs_i18n.py todo --lang de     # the German pages to (re)translate
python tools/docs_i18n.py svg-build --lang de    # German pictures from docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # stamp the German pages with their English hash
python tools/docs_i18n.py check              # exit 1 when hashes or labels are stale
```

Преводите само оно што `todo` наводи: Markdown, везе, код, имена фајлова и колона оставите како јесу, преводите наслове и опис слика, и користите речи самог 3DHeat прегледача за његова дугмад и панеле (његов `src/i18n/locales/<lang>/`). Генерисане странице с референцама и слике терминала остају на енглеском. На сајту застарели превод то каже и води на енглеску страницу; недостајући пада на енглески. Мени језика у заглављу и преусмеравање по језику прегледача на почетној страници долазе из `docs/_includes/`.
